# Simple Video Editor

간단한 타임라인 기반의 영상 편집 및 내보내기 기능이 포함된 웹 기반 비디오 편집기입니다.
Chrome 등 모던 브라우저에서 바로 실행되며, 별도의 데스크톱 앱 설치가 필요 없습니다.

## 실행 방법

### 1. 사전 요구 사항
- **Node.js**: [공식 홈페이지](https://nodejs.org/)에서 Node.js를 다운로드하여 설치하세요. (LTS 버전 권장, v18 이상)

### 2. 패키지 설치
```bash
npm install
```

### 3. 개발 서버 실행
```bash
npm run dev
```
터미널에 표시된 URL (기본: `http://localhost:5173`)을 **Chrome 브라우저**에서 열면 됩니다.

### 4. 프로덕션 빌드
정적 파일로 빌드하여 웹 서버에 배포하려면:
```bash
npm run build
```
빌드된 파일은 `dist/` 폴더에 생성됩니다.

## 주요 기능 및 사용법
1. **미디어 불러오기**: 좌측 상단의 `미디어 추가` 영역을 클릭하여 동영상(MP4 등) 및 오디오(MP3, WAV) 파일을 추가합니다.
2. **타임라인 배치**: 미디어 패널(Media Bin)에 추가된 클립의 `담기` 버튼을 클릭하면 타임라인에 자동으로 배치됩니다.
3. **클립 편집 (트림 및 이동)**: 타임라인에 배치된 클립의 양끝을 마우스로 잡아당겨 길이를 자르거나 늘리고, 클립 몸통을 드래그하여 원하는 시간대로 이동시킬 수 있습니다.
4. **미리보기**: 키보드의 `Spacebar` 또는 화면 중앙의 재생 버튼을 눌러 현재 타임라인의 작업물을 실시간으로 미리볼 수 있습니다.
5. **음향 분리**: 비디오 클립에서 오디오만 추출하여 별도의 오디오 트랙으로 분리할 수 있습니다. (FFmpeg.wasm 사용)
6. **영상 내보내기 (Export)**: 우측 상단의 `내보내기` 버튼을 눌러 최종 편집된 타임라인을 **MP4 파일**로 렌더링하고 다운로드합니다. (FFmpeg.wasm 사용)

## 기술 스택
- **프론트엔드**: React, Vite, Lucide React (아이콘 세트)
- **미디어 렌더링 엔진**: FFmpeg.wasm (브라우저에서 WebAssembly로 실행되는 FFmpeg)
- **스타일링**: Vanilla CSS (다크 테마, 글래스모피즘)
